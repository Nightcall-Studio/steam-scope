# 🎮 SteamScope

**SteamScope** is a web app by **Nightcall Studio** that helps users discover Steam games currently **on sale**, **free to play**, or **trending** — all powered by live data from the **SteamSpy API**.  
Built with **Next.js** and **Tailwind CSS**, SteamScope provides a clean, fast, and responsive experience with built-in **sorting** and **filtering** to help you find your next favorite game.

---

## 🚀 Features

- 🕹️ **Live Steam Data** — Uses the [SteamSpy API](https://steamspy.com/api.php) to display updated game information.
- 💸 **Sales & Discounts** — Instantly browse games currently discounted or free.
- 🔍 **Advanced Filtering** — Filter games by genre, price range, discount amount, and more.
- 📊 **Sorting Options** — Sort by name, price, popularity, or review ratio.
- ⚡ **Built with Next.js** — Server-side rendering for speed and SEO.
- 🎨 **Tailwind CSS UI** — Modern and responsive design with smooth UI interactions.
